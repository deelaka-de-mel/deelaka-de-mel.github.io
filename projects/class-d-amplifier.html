Class D Amplifier

A 300 kHz Class D amplifier with a custom gate driver subsystem, switch-node diagnostics, RC snubber tuning, and bootstrap gate driver coverage.

Hardware · Power Electronics · Completed

3D PCB

Gallery

Overview

This project centers on a class D audio amplifier design focused on high-frequency efficiency, careful gate drive behavior, and practical hardware validation.

Motivation

The goal was to understand the working of a class D amplifier, especially switching transitions, driver timing and Bootstrap design.

Problem Statement

The amplifier needed to address switch-node ringing, reliable gate drive operation, and signal integrity during high-frequency switching.

Features

  • Custom gate driver subsystem
  • Bootstrap driver arrangement
  • Simulation-driven Circuit

Software Used

  • LTspice
  • Altium Designer

Challenges Faced

  • High frequency compatibility with available local Integrated circuits.
  • I designed the first iteration of the gate driver using transistors, the bootstrap circuit using a capacitor and a Schottky diode, and implemented dead time uing a resistor capacitor network.
  • This was unsuccessfull as the Diode-Resistor Gate couldn't provide an adaptive dead time for the varying duty cycle provided by the gate drivers. This caused cross conduction in the half bridge, heating up the mosfets and current limiting the power supply.

Insights Gained

  • Constraints faced when operating at high frequencies, which include signal distortion, higgh frequency ringing.
