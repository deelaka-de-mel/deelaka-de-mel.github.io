Class D Amplifier

A 300 kHz Class D amplifier with a custom gate driver subsystem, switch-node diagnostics, RC snubber tuning, and bootstrap gate driver coverage.

Hero Image

Gallery

Overview

This project centers on a switch-mode audio amplifier design focused on high-frequency efficiency, careful gate drive behavior, and practical hardware validation.

Motivation

The goal was to understand the real constraints of power electronics design, especially switching transitions, driver timing, and layout-sensitive behavior.

Problem Statement

The amplifier needed to address switch-node ringing, reliable gate drive operation, and signal integrity during high-frequency switching.

Features

  • Custom gate driver subsystem
  • Bootstrap driver arrangement
  • RC snubber and ringing analysis
  • Simulation-driven validation workflow

Hardware Used

  • Half-bridge power stage
  • Gate driver circuitry
  • LC filter network
  • Class D switching hardware

Software Used

  • LTspice
  • PCB design tools
  • Simulation and waveform analysis

Challenges Faced

Switch-node oscillations, driver timing stability, and balancing practical implementation with thorough bench-level validation.

Future Improvements

Refining thermal and layout performance for higher power density and stronger manufacturability.
